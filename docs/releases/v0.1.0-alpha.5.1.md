# v0.1.0-alpha.5.1 — client movement smoothing

Client-only hotfix for Captain of Industry 0.8.7d. It remains compatible with
the alpha.5 Windows and Linux servers: **dedicated-prototype-5 / cmd1**.
No server restart, island migration, or replacement join key is needed.

The alpha.5 client reset the game's visual interpolation every frame, causing
vehicles and other animated world objects to move in visible steps while the
camera and UI remained smooth. This update advances the native visual clock
between authoritative updates and avoids rendering synthetic packet-replay
frames. Native simulation and command synchronization remain unchanged.

The package retains the exact alpha.5 protocol and game-adapter binaries. Only
the client plugin changes (BepInEx plugin version 0.5.1). Connection settings and
the remembered join-key path are preserved by the installer.

Close CoI, extract `CoI-Multiplayer-Client-0.1.0-alpha.5.1-win-x64.zip`, and run
**Install Client.cmd**. Each player can update independently against an alpha.5
server. Keep the alpha.5 server-manager package and Docker image.

Native clock regression checks cover interpolation, pause/freeze, speeds 1–4,
and late packets. Actual Unity visuals still require an in-game check. This
does not address periodic checkpoint stalls or add gameplay command support.
See [movement timing details](../movement-smoothing.md).
