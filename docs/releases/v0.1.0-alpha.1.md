# v0.1.0-alpha.1

First public **Windows x64 alpha** of the Captain of Industry dedicated server, matching game client, and local browser manager. Requires an installed **CoI 0.8.7d** copy on the host and each player's PC. This is an independent project, not an official CoI server or a CoopFoundry extension.

## Downloads

- [**Server-manager ZIP**](https://github.com/nebula-codes/coi-dedicated/releases/download/v0.1.0-alpha.1/CoI-Server-Manager-0.1.0-alpha.1-win-x64.zip): extract and run **Start Server Manager.cmd**. The included runtime removes the need to install .NET separately. See the [hosting guide](https://github.com/nebula-codes/coi-dedicated/blob/v0.1.0-alpha.1/docs/hosting-guide.md).
- [**Client ZIP**](https://github.com/nebula-codes/coi-dedicated/releases/download/v0.1.0-alpha.1/CoI-Multiplayer-Client-0.1.0-alpha.1-win-x64.zip): close the game, extract, and run **Install Client.cmd**. Start the game, press **F8** at the main menu, and join using the host's address, player port, and private `join.key` file. See the [player guide](https://github.com/nebula-codes/coi-dedicated/blob/v0.1.0-alpha.1/docs/player-guide.md).
- **Source:** available in the repository and GitHub's source archives. Game binaries, game assets, saves, and keys are not included.

Use matching server/client releases, exact game assemblies, and matching DLC configurations. The base game was used for validation; other mods and DLC combinations have not been established as compatible.

## Included

- A standalone headless island process with unattended simulation, persistence, autosave, and graceful shutdown.
- Authenticated player joins, verified snapshot downloads, ordered commands and ticks, and reconnecting from a fresh snapshot.
- A browser manager at `http://127.0.0.1:28560`: profiles, start/stop/restart, pause/resume/save, live status, player counts, resource information, logs, backups, import, restore, and private player-key download.
- Server processes survive the manager closing; reopening it reconnects to recorded processes.
- Shared pause, speed 1, ordinary machine and standard-storage placement, construction priorities, recipe toggles, ordinary deconstruction, and construction toggles.

## Alpha limits

**This is not complete co-op gameplay.** Roads, belts, pipes, other transports, terrain editing, batch placement, many specialized buildings, and broader management actions remain unsupported. Unsupported actions are rejected. See [command coverage](https://github.com/nebula-codes/coi-dedicated/blob/v0.1.0-alpha.1/src/CoiDedicated.GameAdapter/README.md).

Full cross-runtime state equality, long sessions, large islands, and broad DLC/mod compatibility remain unproven. Automatic desynchronization repair, full-state checksum exchange, Windows service installation, reboot startup, and crash restart are not implemented. A disconnected or out-of-step client freezes and must return to the main menu to reconnect. Use a test island with backups.

The gameplay port is **TCP 28551** by default. Use a trusted LAN or a VPN: transport is not encrypted. Keep admin port **28550**, manager port **28560**, and `control.key` private; share only `join.key` with your player group.

## Validation performed

Independent headless peers replayed shared ticks and commands, including placement and reconnect. Two actual Unity client runs completed 100 authoritative ticks; tests covered remote building placement and accepted/rejected input completion. A later installed-client smoke completed another 20 ticks.

The real manager integration exercised authentication checks, import and restore, unattended host simulation, pause/resume/save, live backup and hash-verified download, rejection of running-server edits, manager termination and exact-process reattachment, and graceful final-save preservation. All seven integration groups passed. These bounded tests do not establish long-term multiplayer stability. See [runtime evidence](https://github.com/nebula-codes/coi-dedicated/blob/v0.1.0-alpha.1/research/runtime-validation.json).
