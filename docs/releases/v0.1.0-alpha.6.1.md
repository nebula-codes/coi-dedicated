# Alpha.6.1 — server-only startup and native Linux hosting

Server patch release for **Captain of Industry 0.8.7d**. The dedicated host no longer starts or authenticates a Steam client. Linux hosting runs directly on .NET, removing Wine, the Steam desktop, and Steam sign-in from Docker setup.

- Applies the reviewed startup compatibility state inside the dedicated process before creating or loading any world. No installed game DLLs or executables are rewritten; normal game-client startup is unchanged.
- Checks the exact SHA-256 of all three simulation assemblies, including the files actually loaded at runtime. Unknown game updates stop before bootstrap can replace an island. Compatibility must be reviewed for each new game build; there is no automatic guessing or patching of unknown versions.
- Keeps player join keys, administrator control keys, gameplay validation, and exact client/server game fingerprints. **Existing alpha.6 clients remain compatible** (`dedicated-prototype-6 / cmd1`); this release does not add command schemas.
- Restores a native Linux/amd64 server package and simpler Portainer stack. The complete matching game installation is still supplied privately by the host.

For an existing Wine stack, preserve its data volume and independent island backup, use the updated Compose file, and select the new image after publication. Remove `COI_AUTH_ONLY` and the Steam desktop/profile configuration from the stack. The old private Steam volume can remain stored; the new image does not use it. See the [Docker guide](https://github.com/nebula-codes/coi-dedicated/blob/main/docs/docker-portainer.md).

Validation passed on Windows and native Linux: the delayed-failure fixture retained all 97 people and 16 vehicles after 120 placements and 3,100 updates. Fresh Linux world creation, unchanged alpha.6 two-peer replay, save/stop/restart, persistent join keys, and reconnect passed. All five packaged Windows manager lifecycle checks passed. Results and remaining limits are recorded in the [startup ledger](https://github.com/nebula-codes/coi-dedicated/blob/main/docs/server-startup-validation.md). This remains an experimental multiplayer server; the remote NAS deployment, human Unity clients against this Linux release, specialized Unity UI paths, and long sessions still require testing.

Public packages contain only the project's redistributable host/client tools and their dependencies, never game binaries, islands, credentials, or keys. Windows players can keep their existing alpha.6 installation; new players can use the matching client ZIP.
