# v0.1.0-alpha.4 - Truck assignment candidate

Fixes the rejected add/remove trucks controls in a tree harvester's inspector. The same native vehicle-type assignment commands serve other compatible entity inspectors. Normal vehicle availability, compatibility, counts, zone selection, and simulation scheduling remain controlled by the game.

Requires **CoI 0.8.7d** and matching client/server builds with compatibility **dedicated-prototype-4 / cmd1**. Alpha.3 clients cannot join an alpha.4 server; upgrade the host and every player together.

## Validation

- Eleven adapter test groups pass, including exact assignment wire fixtures, optional zones, bounded counts, invalid flags/zone IDs, truncation, and trailing-data rejection.
- Eight isolated native scenarios on a copied live island passed: two-truck assignment/removal to an existing tree harvester; direct individual assignment/removal; both ownership links; explicit zone selection and removal behavior; zone IDs larger than 63; and invalid target/prototype rejection.
- The Unity inspector buttons were traced to the added commands. Actual two-player UI interaction with this new build remains an in-game check after installation.

This candidate includes the earlier expanded gameplay and camera/building-outline features. Full gameplay parity remains incomplete; see [coverage](../multiplayer-coverage.md). Road/surface tools, blueprints/copied settings, advanced rail, and several detailed controls are still missing. Simulation speed remains 1.

Generating these packages does not update an already-running server. Close CoI on all clients, back up and stop the host, install matching binaries, then restart and reconnect with the existing player key.
