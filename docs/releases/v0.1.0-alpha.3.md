# v0.1.0-alpha.3 — Gameplay expansion candidate

Development candidate, not full multiplayer parity. Requires **CoI 0.8.7d** and matching new server and client binaries; compatibility is **dedicated-prototype-3 / cmd1**. Older alpha.1/alpha.2 clients cannot join this build.

- Fixes normal building-menu input by preserving native batch placement and its result/callback timing. Broadens ordinary building support to player-buildable layout prototypes.
- Adds the blocked ruins, crew, harvesting, navigation, and enable/disable commands, plus explicit adapters for many storage, research, vehicle, ship, factory, mining, and farming controls. The adapter recognizes 124 concrete command classes; this is not a gameplay completion percentage.
- Adds optional camera focus labels, approximate view rectangles, and building footprint outlines. Set a recognizable player name before joining in F8; the show/share toggle controls these indicators. Presence uses a separate bounded channel and expires after three seconds.
- Bounds larger building/transport plans and total tick payload size. Construction costs and game validation remain active.

## Checks

Protocol and adapter unit tests and live-session/snapshot transport fixtures pass. Isolated native tests place nine building families and exercise early-game, storage, planning, farming, work-area, and terrain commands. Two separate simulation peers replayed 100 shared ticks including batch construction and produced identical serialized world hashes. A separate two-peer socket test verified presence relay, hiding, expiry, and disconnect cleanup.

This does not establish all-menu or long-session compatibility. Actual Unity overlay appearance, two human clients using the expanded menus, long-session determinism, and every individual command schema still need testing. The live local island is not automatically migrated by generating this candidate.

## Remaining limits

Speed remains 1. Blueprint/copied settings, road/surface tools, rail/bridge plans, advanced trains, some vehicle/zone controls, and many detailed inspector actions remain unsupported. Automatic state checksums/resynchronization are not implemented. Building previews are bounded footprint outlines, not textured ghosts, and specialized tool previews are not yet included.

See [the detailed coverage ledger](../multiplayer-coverage.md). Everyone should close the game before installing the matching candidate; save and stop the host before replacing its binaries. Keep the island and existing private join key. Candidate packages contain no game assemblies, saves, or credentials.
