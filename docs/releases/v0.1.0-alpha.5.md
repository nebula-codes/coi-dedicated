# v0.1.0-alpha.5 — gameplay, state checks, and remembered connections

Experimental dedicated multiplayer for **Captain of Industry 0.8.7d**, Windows x64 clients, and Windows or Linux x64 servers. Install the matching alpha.5 client and server together: **dedicated-prototype-5 / cmd1** intentionally rejects older builds.

## Changes

- F8 remembers the host, port, player name, and normalized join-key path across game and PC restarts. It saves only the path, never key contents; control-key previews do not replace the saved player connection.
- Native building batches, inspector truck assignment (including tree harvesters), research, transports, terrain, storage, and many common gameplay controls replace the initial seven-command public alpha.
- Roads/paving, decals, logistics zones, truck rules, and additional factory, farm, forestry, and depot settings expand gameplay further. See the [coverage ledger](../multiplayer-coverage.md) for exact supported variants and native test evidence.
- Bridge/rail plans and basic train line, network, and schedule editing bring the adapter to **199 command classes / 200 wire schemas**. Native fixtures cover one bridge entrance, ground rail, and basic train schedule lifecycle; elevated/electrified and complex variants remain unverified.
- Structural train schedule edits are admitted separately and revalidated after the previous tick; membership guards reject unrelated stations. This prevents the identified stale-index native crashes, but does not resolve every simultaneous edit conflict when an index still exists after a reorder.
- Copied settings for ordinary machines and storage preserve recipes, products, storage sliders/alerts, pause, logistics, priorities, and titles. Unknown settings and external assignment graphs are rejected; arbitrary complex blueprints are not supported.
- Shared speeds **1–4×** use deterministic native step budgeting. Higher speeds are rejected.
- Selected-state checkpoints detect divergence beyond tick/step mismatches. Clients freeze and attempt a fresh server snapshot after recoverable failures, with a three-attempt limit, backoff, and F8 cancellation. Manual disconnect never automatically reconnects.
- Player camera markers handle off-screen locations. Cosmetic outlines include active layout buildings, transports, rail plans, paving, and terrain tools, with bounded network updates.
- Matching Windows packages and Linux/Portainer deployment use the same protocol. The container publication workflow now resolves the selected release's archive and checksum instead of always building alpha.2.

## Validation and limits

The actual BepInEx configuration file passed save/reload and invalid-input checks. Reconnect policy and presence geometry/private-field contract tests passed. Two native simulation peers each replayed 1,200 updates across speed changes, pause/resume, building at 4×, and speed-5 rejection, with six matching checkpoints each and identical final raw serialization. An unauthorized local entity-state change was detected; a fresh same-name rejoin replayed another 400 updates. A further five-minute revision-5 soak passed 3,000 updates and 11 matching checkpoints per peer, again with identical final raw serialization. See [synchronization evidence and timing](../synchronization.md).

This is **not full gameplay parity**. Unsupported actions fail visibly. Checkpoints compare selected canonical state, not every private game field; a full terrain scan can cause a brief pause. New Unity overlay visuals and the automatic scene-reload flow still need an actual two-player in-game check. Headless tests do not replace that check or establish large-island, multi-hour stability. Other mods and DLC combinations remain unvalidated.

## Downloads and upgrade

- Players: `CoI-Multiplayer-Client-0.1.0-alpha.5-win-x64.zip`. Close the game, extract the ZIP, run **Install Client.cmd**.
- Windows hosts: `CoI-Server-Manager-0.1.0-alpha.5-win-x64.zip`. Stop profiles and close the manager before replacing binaries; retain the entire data directory.
- Linux hosts: use `ghcr.io/nebula-codes/coi-dedicated:0.1.0-alpha.5` and [the Portainer stack](../../compose.portainer.yml), or the checksum-pinned source-build stack. The Linux ZIP is framework-dependent server/control code; the image supplies .NET 10.

Back up the island before upgrading. Every player needs their own matching game installation and the host's private `join.key`. The key does not need to change when updating. Public downloads contain no game binaries, saves, or player/admin keys. Use a trusted LAN or VPN.
