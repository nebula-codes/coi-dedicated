# Alpha.6.3 — ten-minute player joins

The server gives an authenticated player **600 seconds (ten minutes)** to download and load the island and report ready, increased from 60 seconds. This helps players whose islands load slowly. Simulation remains paused while a player joins; a stalled join still expires after the deadline.

The matching client extends its join-download timeout to 610 seconds, covering authentication plus the join window. The client no-tick watchdog and server peer-read timeout are 615 seconds so players already connected can wait through the longer loading pause. Authentication itself remains limited to ten seconds, and the separate administrative snapshot-preview download retains its existing timeout.

## Update the server and every player

**Install alpha.6.3 on the server and every player's client**, including players who already load quickly. The wire protocol remains revision 6, so older alpha.6 clients can connect, but their shorter download and no-tick limits can still interrupt long joins. Exact matching Captain of Industry **0.8.7d** game files are required as before.

- **Windows players:** close Captain of Industry, extract `CoI-Multiplayer-Client-0.1.0-alpha.6.3-win-x64.zip`, and run `Install Client.cmd`. Use the existing server address and private `join.key`.
- **Windows hosts:** back up the island and stop the server before installing the matching `CoI-Server-Manager-0.1.0-alpha.6.3-win-x64.zip` package.
- **Docker / Portainer hosts:** back up the island, keep the existing game path and data volume, set `COI_IMAGE=ghcr.io/nebula-codes/coi-dedicated:0.1.0-alpha.6.3`, and update with image re-pull enabled. The browser manager remains on TCP 28560 and player connections on TCP 28551 by default. No new Compose setting is needed for the timeout.

The native Linux startup compatibility handling, server-manager authentication, saves, and join keys are unchanged. The server still needs no Steam client, Wine, or VNC. The Linux archive contains the host, control tool, and manager used to build the image. No game binaries, private saves, or credentials belong in public packages.

## Validation and publication

All 13 protocol checks passed. The packaged host passed a two-peer TCP test with an 85-second loading pause and no keepalives from the established player. Both peers remained connected, readiness released the join barrier, and both acknowledged the resumed authoritative tick. Controlled peer-age checks kept a loading peer at 599 seconds and expired it at 601 seconds; the packaged 600/610/615-second limits were verified. These checks did not run a full ten-minute Unity loading session.

The Windows server package passed five integration groups under PowerShell 5.1, using its bundled runtime: launcher/dashboard assets, copied-island startup and simulation, checksum-verified live backup, manager termination and reattachment, and graceful final save/stop. The actual packaged client installer, repeat installation, and uninstaller passed against an isolated fake game. All 24 payload manifest hashes matched; original fixture files, the shared loader, and an unrelated mod were preserved.

The Docker container passed five copied-island integration groups covering authenticated access, pause/resume/save/logs and verified backups, import/restore, persisted settings/session/stopped state, dashboard restart, and Docker shutdown/restart. The island and keys were preserved; shutdown exited cleanly in 1.12 seconds. Logout revoked browser access and the original source fixture remained unchanged.

Remote NAS deployment, human Unity gameplay with this release, and multi-hour sessions remain unverified. Prior release tests are documented separately in the [Docker setup guide](https://github.com/nebula-codes/coi-dedicated/blob/main/docs/docker-portainer.md).
